## 完成个人实践

1. `input/` 第一层已准备好 5 张课堂示例图片 `sample-01.jpg` 至 `sample-05.jpg`；再自行补充 2–3 张新图片，共 7–8 张。格式为 JPG、JPEG、PNG 或 WebP；先将 HEIC 等其他格式转换为支持格式。
2. 在本周 `.env` 中填入同一 Model Studio 工作空间的密钥和 OpenAI 兼容端点，并检查模型权限与可用额度。实际密钥不要放到本文件、结果记录、GitHub 或视频里。
3. 双击项目根目录 `Open-Course.cmd`，依次执行 `python app.py --check`、`python app.py --test-api`。前者离线；后者会请求 API，可能消耗额度。
4. 执行 `python app.py` 完成图片分类。这一步会把输入图片发送给 Qwen；原图保留，分类副本写入 `sorted/`。
5. 检查终端中每一张图片的结果，以及 `sorted/` 中的分类图片。将实际观察填到同目录 `results.csv`，保留真实失败或误判，不修改为预期答案。
6. 若只使用 2 张新图片，删除或标注 `results.csv` 中第 3 张新图片的占位行。将记录里的图片文件名改为实际文件名；5 张课堂样例预期依次为 `person`、`document`、`food`、`device`、`other`，实际输出须运行后填写。
7. 修改代码或说明后，在项目根目录检查、提交并推送到 GitHub；随后录制下方演示视频。

## 30–60 秒录屏脚本

建议录制约 50 秒，按课程要求依次展示四个部分。关闭 `.env` 编辑窗口；录屏前不要显示 API 密钥。请保留原始录像；若因模型等待导致视频超过 60 秒，先向教师确认是否允许加速等待片段，再按要求处理。

1. **0–10 秒：展示 `input/` 全部图片。** 展开文件夹，让 5 张课堂样例和自己准备的 2–3 张新图片都能看到。可口述：“我是 WANG HAOBIN，这是第 2 周照片分类项目，输入包含课堂示例和新增图片。”
2. **10–20 秒：展示运行命令。** 在课程终端输入并执行 `python app.py`，画面中保留可辨认的命令。可口述：“运行程序后，图片会发送给 Qwen，并按识别类别复制到结果目录。”
3. **20–35 秒：展示全部分类结果。** 待实际运行结束，显示每张图片的分类输出及成功/失败汇总；必要时滚动终端，避免只露出最后一行。可说明真实观察到的正确结果或误判。
4. **35–50 秒：展示 `sorted/` 分类图片。** 展开实际生成的分类目录，展示其中图片并与终端结果对应。未生成的空类别不用伪造。最后可口述一项真实发现或待改进点。

视频应能看清输入、执行过程和真实输出；**课程作业详情没有要求另交截图**。`results.csv` 是方便自查和说明的本地记录，不代替运行视频，也不是课程额外规定的必交项。
