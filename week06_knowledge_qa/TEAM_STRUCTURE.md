# 第六周小组项目结构（6-1）

项目：入住有数 · 宿舍入住准备助手。成员与负责人：WANGHAOBIN（一人）。目标使用者是需要查看东亚大学翰林生活馆一般入住说明并整理准备事项的学生；界面也提供韩语。留学生和不确定适用身份者只把一般说明作为参考，须向生活馆确认本人材料与办理流程。程序不核实证件、不判断入住资格。

## 用户问题与连续追问

示例对话：①“可以带电热水壶吗？”→ ②“那冰箱呢？”。第二轮必须把“那……呢”理解为同一“能否带入宿舍”的问题。其他可问材料开具期限、领取出入证、洗衣用品。若问“奖学金申请日期是什么”，资料库不涉及此项，应如实说明检索未命中，不给出编造日期。

## 输入、检索与回答流程

1. 浏览器将当前问题、所选语言以及最近三轮问题和已引用条目 ID 发送到 `/api/conversation`。准备状态、日期和完整页面问答不会随该请求传入；本机浏览器内的对话在清空或刷新后消失。
2. Qwen 把追问改写成独立问题，提取 2–5 个韩文检索词；不符合格式时退回受约束的本地改写。网页显示实际独立问题及检索词，便于发现改写错误。
3. 本地程序根据原问题、韩文词、双语同义提示和上轮已引条目排序。默认最多选三个主题条目；如果某条目依赖必要条件，会把条件一起带入检索结果，如禁带用品旁的健康用途咨询、材料旁的三个月开具时限。来源由本地知识库映射，Qwen 不能发明 URL。
4. Qwen 只判断条款是否直接支持答复，并选择被检索条目 ID。可见答复使用本地核过的中韩条目表述，连同标题、条款、简短原文与 URL 呈现。未命中是 **retrieval** 问题；有命中却不足以回答是 **answer** 问题，两者有不同提示。
5. 用户对照原文及所属馆、所属学期的最新通知；国际生具体材料、替代关系和个人资格交由学校确认。
