# Mission B：准备状态核对与行动清单

负责人：**WANGHAOBIN**。项目代码目标目录：`week03_dorm_assistant/`。

这是已实现 MVP 的功能规格与验收记录。技术及界面验证已完成，真实用户测试尚未开展。

## 功能规格

- **功能名称**：入住准备状态核对与行动清单。
- **用户行为**：选择适用配置，填写准备情况，检查清单，保存或导出。
- **触发条件**：用户主动请求检查；使用 AI 建议时，先展示建议，再由用户确认。
- **输入**：`standard / international / unknown` 配置；官方清单项目；用户手动状态；可选自然语言准备描述。
- **系统处理过程**：读取有来源的项目与适用范围，获取用户状态；可选 AI 解析建议经用户确认后，按确定性规则生成缺项、待确认项及行动清单。
- **输出**：每项准备状态、待办动作、来源与原文依据；尚未覆盖的问题；可保存和导出的核对记录。输出是准备辅助结果，不是学校批准结果。
- **模型／API／数据**：通过 Qwen 的 OpenAI 兼容 API 解析自然语言和回答资料内问题；实际模型名以运行证据为准。数据是官方条目、适用范围和用户准备状态。清单规则不由模型临时编造，国际生要求资料不足时必须保留“需确认”。
- **正常流程**：选择配置 → 阅读范围 → 填状态或确认 AI 建议 → 核对待办与来源 → 保存／导出。
- **异常情形**：资料不足、空输入、含糊或矛盾描述、无效模型返回、缺少 API 配置、超时、保存／导出失败。
- **用户反馈**：显示具体缺项与待确认项；说明 AI 建议尚需本人确认；错误时提供手动继续入口。固定界面说明不验证材料真实性、不判断入住资格。
- **完成判断**：一个用户能从配置选择走到保存／导出；未知信息始终保持未知；AI 建议必须经过确认；正常和失败场景有实际证据。

AI 的作用是把自然语言描述转成待确认的状态建议，并辅助资料内问答。入住事实以[公开入住说明](https://hanlim.donga.ac.kr/hanlim/CMS/Contents/Contents.do?mCode=MN075)中实际收录的条目为准；[官方规则页](https://dms.donga.ac.kr/hanlim/15139/subview.do)仅用于其原文确实支持的结论。

## 与 Mission A 的差别

Mission A 处理“规定是什么、依据是什么”；Mission B 处理“根据我填写的准备状态，接下来需要做什么”。B 必须能在不开启 AI 的情况下完成手动核对；AI 是可选输入辅助，不是唯一可用入口。

## 流程

```text
选择适用配置 → 阅读资料范围 → 手动填写状态 ─────────────┐
                        → 自然语言描述 → AI 建议 → 用户确认 ┤
                                                         ↓
                                      规则核对 → 待办与来源
                                                         ↓
                                               保存／导出

资料不足 → 保留“需确认”并给出官方咨询入口或来源
AI 不可用／返回异常 → 说明失败，继续使用手动核对
```

## 正常与异常行为

- 手动填写后，核对结果必须与用户输入一致，不能出现模型替用户“补齐”的项目。
- 国际生或未知配置遇到适用范围不足时，醒目标记待确认，不能输出“全部材料齐全”。
- AI 对含糊描述应提出待确认建议；未经确认，不覆盖已保存的手动状态。
- 空描述、矛盾描述、无效 AI 返回、超时或缺少 API 配置，应给出可理解的提示并保留已输入内容。
- 对资料外问题说明无法确认，不能使用常识冒充入住说明。
- 保存／导出失败时告知用户；成功后文件应可重新读取，并能辨认它来自哪个资料范围。

## 验收清单

- [x] `standard` 用户能完成完整的手动核对、保存和导出流程。
- [x] `international` 与 `unknown` 用户不会因为资料缺失被判定为“全部齐全”。
- [x] 官方条目和由它产生的待办能追到项目收录的来源；出入证条目已修复为展示双来源。
- [x] AI 建议确认前不改正式状态；界面实测床品在确认前保持 missing，主动确认后变为 ready。
- [x] AI 未配置时按钮禁用，手动核对仍成功；异常脱敏和私有路径拒绝等 HTTP 检查通过。
- [x] 刷新恢复成功，真实下载导出的状态与界面一致；导出不包含自由描述文本。
- [x] 真实 Qwen、确定性合成案例、离线测试和界面验证分别保留了实际输入、输出及证据。

当前 MVP 验收状态：**技术与界面检查通过；尚未开展真实用户测试**。这些结果不代表学校审核或通用准确率。
